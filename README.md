# XHR-Fetch-Stealth-Interceptor 🕵️‍♂️

A zero-dependency, client-side network interception engine. It silently hooks into native `XMLHttpRequest` and `Fetch API` to capture dynamic authorization headers and cache API responses in real-time, all without triggering anti-bot mechanisms.

## Why Build This?
In complex Single Page Applications (SPAs) or highly secured enterprise portals, authentication tokens (like JWTs or dynamic signatures) are heavily obfuscated and rotated constantly. Standard Web Scraping or E2E automation tools often fail because they cannot reverse-engineer the encryption logic. 

Instead of fighting the obfuscation, this tool acts as a "wiretap" at the browser's lowest network layer, extracting valid headers right before they are sent to the server.

## Key Features
- **Token Extraction:** Silently captures dynamic headers (e.g., `Authorization`, `CompanyCode`, etc.) generated by the frontend.
- **Response Caching:** Clones the Fetch response stream and listens to XHR `load` events to cache JSON responses into memory.
- **Zero-Trace:** Designed to be completely transparent to the host application. It wraps native methods without breaking the execution context (`this`), avoiding common anti-tampering detections.

## Ideal Use Cases
- Advanced RPA (Robotic Process Automation) interacting with secured gateways.
- Headless browser data extraction without setting up heavy proxy servers (like Charles or Mitmproxy).
- Bypassing frontend encryption by hijacking the final plaintext payload.
